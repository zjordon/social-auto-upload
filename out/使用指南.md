# social-auto-upload - 使用指南

> 生成时间: 2026-11-04
> 依据: README.md、docs/install.md、docs/CLI.md、conf.example.py、sau_commands/ 源码

## 1. 项目简介

social-auto-upload 是一个多平台内容发布工具：一条 `sau` 命令把视频/文章/图文发布到抖音、Bilibili、小红书、快手等 17 个平台。核心思路是"本地 cookie 会话 + 浏览器自动化"，不需要各平台官方 API。同时提供 18 个 Agent Skill，可被 Claude Code / Codex / OpenClaw 等直接调用。

**能力速查**（✅ 支持 / - 不适用）：

| 内容形态 | 平台 |
|----------|------|
| 视频 | 抖音、快手、小红书、Bilibili、视频号、百家号、大鱼号、支付宝生活号、微博、虎扑、TikTok、YouTube、知乎、Facebook(+Page)、Instagram |
| 文章 | 大鱼号、雪球、知乎（均支持 HTML/Markdown/TXT + 正文配图） |
| 图文（图片帖） | 抖音、快手、小红书、Facebook、Facebook Page、Instagram |
| 定时发布 | 抖音、快手、小红书、Bilibili、视频号、大鱼号、Facebook Page、知乎（实验性）等 |

## 2. 安装

### 2.1 环境要求

| 依赖 | 要求 | 用途 |
|------|------|------|
| Python | 3.10 – 3.12（<3.13） | 运行时 |
| uv（推荐）或 pip | 任意新版 | 安装 |
| Node.js | 22+（可选） | 仅 Markdown 主题文章渲染 |
| Chrome/Chromium | 可选 | 默认用 patchright 自带 chromium；`conf.py` 里 `LOCAL_CHROME_PATH` 可指定本机 Chrome |

### 2.2 安装步骤

```bash
git clone https://github.com/dreammis/social-auto-upload.git
cd social-auto-upload

# 1. 生成配置文件（必须）
copy conf.example.py conf.py        # Windows
cp conf.example.py conf.py          # Linux/macOS

# 2. 安装（推荐 uv）
uv tool install .
# 或开发安装
pip install -e .
```

### 2.3 配置文件说明（conf.py）

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `BASE_DIR` | 自动 | 项目根目录，勿改 |
| `LOCAL_CHROME_PATH` | `""` | 本机 Chrome 路径，如 `C:/Program Files/Google/Chrome/Application/chrome.exe`；留空用 patchright chromium |
| `LOCAL_CHROME_HEADLESS` | `True` | uploader 默认无头模式 |
| `DEBUG_MODE` | `True` | 调试日志 |
| `YT_PROXY` | `None` | YouTube 被墙地区设代理，如 `http://127.0.0.1:7890`（chromium 不吃系统代理，必须显式指定） |
| `XHS_SERVER` | 本地地址 | 仅旧版 xhs 流程使用，可忽略 |

## 3. 快速开始

### 3.1 第一步：登录账号（每平台一次）

`--account` 是你给本地会话取的名字（如 `creator`），用于区分多账号；登录时弹出浏览器扫码。

```bash
sau douyin login --account creator
sau douyin check --account creator     # 校验 cookie，输出 valid/invalid
# 平台名可换: bilibili kuaishou xiaohongshu tencent baijiahao dayu
#             alipay weibo hupu xueqiu zhihu youtube facebook
#             facebook-page instagram
```

- 终端会直接渲染二维码（Windows 建议用 Windows Terminal）；显示不完整就打开项目目录下的 `qrcode*.png` 扫码。
- Bilibili 登录建议在本地真实终端执行；CLI 不要求预装 `biliup`，首次运行自动下载。
- YouTube 登录是交互式 Google 账号登录（无二维码）。

### 3.2 发布视频

```bash
sau douyin upload-video --account creator --file videos/demo.mp4 --title "示例标题" --desc "示例简介"
sau bilibili upload-video --account creator --file videos/demo.mp4 --title "标题" --desc "简介" --tid 249
sau tencent upload-video --account creator --file videos/demo.mp4 --title "标题" --desc "简介" --tags tag1,tag2
sau youtube upload-video --account creator --file videos/demo.mp4 --title "标题" \
    --tags tag1,tag2 --playlist "我的系列" --visibility public
sau facebook-page upload-video --account creator --file videos/demo.mp4 --title "标题" --desc "简介" --page "我的Page"
```

常用可选参数（以抖音为例，`sau_commands/douyin.py`）：

| 参数 | 说明 |
|------|------|
| `--tags tag1,tag2` | 逗号分隔标签，自动去 `#` |
| `--schedule "2026-11-05 10:30"` | 定时发布（格式 `%Y-%m-%d %H:%M`，须晚于当前 2 小时） |
| `--thumbnail-portrait/--thumbnail-landscape` | 封面图（3:4 / 4:3） |
| `--product-link/--product-title` | 抖音带货链接 |
| `--declaration` | 抖音原创声明选项原文 |
| `--collection` | 加入已有合集名 |
| `--headed` / `--debug` | 有头浏览器 / 调试模式（所有平台通用） |

### 3.3 发布图文（upload-note）

```bash
sau douyin upload-note --account creator --images videos/1.png videos/2.png --title "图文标题" --note "图文正文"
sau xiaohongshu upload-note --account creator --images a.jpg b.jpg --title "标题" --note "正文"
sau instagram upload-note --account creator --images a.jpg b.jpg --title "图片轮盘" --note "正文"
sau facebook-page upload-note --account creator --images a.jpg --title "图文" --note "正文" \
    --page "我的Page" --schedule "2026-11-05 10:30" --result .local/page-result.json
```

- `--notef file.txt` 可从文件读取正文（txt/md）；抖音图文还支持 `--bgm` 搜索背景音乐。

### 3.4 发布文章（upload-article）

支持大鱼号、雪球、知乎，正文来自 HTML/Markdown/TXT 文件，图片写在原稿对应位置：

```bash
sau dayu upload-article --account creator --title "标题" \
    --content-file examples/dayu_article.html --source "无需标注" --cover-indices 1
sau xueqiu upload-article --help
sau zhihu upload-article --account creator --title "标题" --content-file examples/article.md
```

Markdown 主题渲染（首次需 Node.js 22+）：

```bash
sau article setup                                                      # 安装渲染依赖（npm ci）
sau article themes                                                     # 列出 5 个主题
sau article render --content-file examples/article.md --theme modern --output output/article.html   # 仅本地预览
sau dayu upload-article --account creator --title "标题" --content-file examples/article.md --theme modern --source "无需标注"
```

注意：`sau article render` 只生成本地 HTML 不发表；HTML/TXT 输入不需要 Node.js、不使用 `--theme`。

### 3.5 抖音短信验证（如触发）

程序优先读取项目根目录 `verify_code.txt`（把收到的验证码写进去即可）；在本地交互终端运行时也可直接按提示输入。这让无人值守/Agent 场景可以"写文件"代替"敲键盘"。

### 3.6 代理（Facebook / Instagram / YouTube）

```bash
sau facebook upload-video ... --proxy "http://127.0.0.1:7890"
# 或环境变量: SAU_FACEBOOK_PROXY / SAU_FACEBOOK_PAGE_PROXY / SAU_INSTAGRAM_PROXY
# --proxy "" 表示忽略环境变量强制直连；YouTube 代理在 conf.py 设 YT_PROXY
```

## 4. 多账号与工作目录约定

| 路径 | 含义 |
|------|------|
| `cookies/{platform}_{account}.json` | 每账号一个 cookie 会话文件（login 生成） |
| `qrcode*.png` | 登录二维码临时文件（登录成功后自动清理） |
| `verify_code.txt` | 抖音短信验证码文件 |
| `~/.social-auto-upload/tools/biliup/` | 自动下载的 biliup 二进制 |
| `utils/article_renderer/node_modules/` | `sau article setup` 安装的渲染依赖 |

多账号：给不同 `--account` 名分别 login 即可；不同账号可并行执行（cookie 文件相互独立）。

## 5. AI Agent 用法

把仓库 + [docs/agent-bootstrap.md](../docs/agent-bootstrap.md) 提示词交给 Agent（OpenClaw/Codex/Claude Code），Agent 会按引导安装并用 `sau` CLI 操作。安装单个 Skill 到兼容 Agent：

```bash
npx skills add dreammis/social-auto-upload --skill douyin-upload
# 可选: social-auto-upload(总入口) bilibili-upload xiaohongshu-upload kuaishou-upload
#       tencent-upload baijiahao-upload dayu-upload alipay-upload weibo-upload
#       hupu-upload tiktok-upload xueqiu-upload youtube-upload zhihu-upload
#       facebook-upload meta-upload instagram-upload
```

注意：`sau skill install` **不是**本项目提供的命令。

## 6. 历史遗留 Web 版（不推荐新用）

`start-win.bat` 可一键拉起 Flask 后端（端口 5409）+ Vue 前端，提供扫码登录、账号管理、视频上传发布界面；需要 `pip install -r requirements.txt` + 前端 `npm install`。**官方已声明（docs/legacy-web.md）该形态为历史保留、非主线维护方向**，新用户请使用 CLI / Skill。

## 7. 常见问题

| 问题 | 处理 |
|------|------|
| `conf` 导入失败 / ModuleNotFoundError | 未复制 `conf.example.py → conf.py` |
| 提示 `cookie is missing or expired` | 重新执行对应平台 `sau <platform> login --account <name>` |
| 终端二维码显示乱码 | 用 Windows Terminal（UTF-8），或直接打开目录下 `qrcode*.png` |
| `Markdown 渲染需要 Node.js 22+` | 安装 Node 22+ 后执行 `sau article setup` |
| 定时报错"必须大于当前时间 2 小时" | 平台规则，改晚 `--schedule` |
| Bilibili 首次命令卡在下载 | 在拉取 `biliup` GitHub Release，网络受限时配置代理重试 |
| 平台改版导致选择器失效 | 升级到最新版（本项目持续跟进平台 DOM 变化） |
